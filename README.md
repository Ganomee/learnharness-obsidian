# LearnHarness Obsidian

An Obsidian integration around the pinned original LearnHarness agent, with a disposable demo vault and a GitHub release path for BRAT or manual installation.

- Project, development guide, and current evidence: [learnharness-obsidian/README.md](learnharness-obsidian/README.md) and [project status](learnharness-obsidian/PROJECT_STATUS.md).
- Requirements and MVP map: [requirements](learnharness-obsidian/docs/requirements.md) and [Wayfinder](learnharness-obsidian/docs/wayfinder/complete-learnharness-mvp.md).
- Pinned upstream: `learnharness-obsidian/upstream/learnharness` (submodule).

The current GitHub `main` contains the Wayfinder planning commit. The integration baseline and release assets are still being prepared; mobile support and combined-work licensing remain unverified.
