## Question

Which mobile platforms, OS-version range, and device form factors are part of the MVP support promise, and what physical-device evidence is sufficient for each? R09 requires desktop plus mobile including iOS, but does not name supported OS versions or a device matrix.

Recommended direction: include iOS and Android phones, identify the minimum Obsidian-supported OS versions before the device run, and require a report naming each device, OS, Obsidian version, and the tested learning/persistence flows. Keep tablets out unless a concrete requirement calls for them.
