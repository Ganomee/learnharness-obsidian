# Project status

## Available now
- A standalone Obsidian vault with internal links, templates, daily notes, canvas, and example learning material.
- A pinned, unmodified LearnHarness submodule in the parent development workspace.
- A repository for contracts and independently challenged tests.
- A desktop development plugin: **LearnHarness Lab: Run offline runtime proof** executes the original prober with a mock provider and saves a diagnostic report. See [[00 Start/Runtime proof]].

## Not implemented
- Interactive learning UI, live-provider agent sessions, provider configuration, automatic plan creation, or durable session recovery.
- Mobile runtime verification and real upstream upgrade validation.
- Anki, consolidation, or graph extraction.

The fictional examples demonstrate navigation and data organization. The separate runtime proof executes original agent behavior under a scripted provider. See the parent repository's `docs/progress.md` for verified engineering results and limits.
