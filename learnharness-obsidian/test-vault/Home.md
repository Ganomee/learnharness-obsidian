# LearnHarness · Learning lab

> [!info] Disposable working vault
> This vault is for trying LearnHarness in Obsidian. The interactive workspace starts with the original adaptive prober and teacher using DeepSeek. Set up a DeepSeek key once in **Settings → Community plugins → LearnHarness Lab**. Session records are Markdown in this vault; your personal vault is untouched.

> [!success] Start a real adaptive lesson
> Open **LearnHarness Lab: Open learning workspace**, choose **New session · choose teacher**, and describe what you want to learn in your own words. The original teacher asks about your current understanding, then builds the next lesson from your answers. You can type or speak.

## Start here
1. Open [[00 Start/Quick start]] for the live adaptive lesson setup and the separate offline walkthrough.
2. The hand-written [[20 Sessions/DEMO-001 - Why averages can mislead]] is an offline example; it is not an adaptive live session.
3. Select **Saved sessions** in the workspace to resume a lesson. Session content is stored as Markdown in this vault.
